# Lecture Publishing Package: Template

Copy this file for each lecture into `youtube/publishing-packages/`. Fill everything marked `{}` from the class schedule and the teacher's lesson plan. **Never guess** a lecture number, sub-topic, link, timestamp or date.

| Field | Value |

## B. Before publication
1. **Search intent.** Primary: `{chapter} class {11/12}` or `{sub-topic} {chapter}`. Secondary: `{chapter} neet`, `{chapter in Hindi}`, `{chapter} hindi medium`. Check demand in vidIQ keyword research if the chapter is new.
2. **Title options** (use the formula `{Chapter EN} ({HI}) L{NN}: {Sub-topic} | Class {11/12} {Subject} | NEET 2027 | {Faculty}`)
   - Option 1: …
   - Option 2: …
   - Option 3: …
   - **Recommended:** … (sub-topic within the first 60 characters)
3. **Thumbnail.** Template: {Lecture / One-shot / PYQ / Test}. Big text (≤4 words): `{…}`. Small text: `L{NN} • Class {11/12}`. Visual: faculty cut-out + {one diagram}.
4. **Description**
   ```
   {One line: what the student will be able to do after this class}

   📌 इस lecture में:
   • {sub-topic 1}
   • {sub-topic 2}

   ⏱ Chapters: (add after the stream, from real timestamps only)

   ⏮ पिछला lecture: {link}
   📚 पूरी playlist: {link}
   (⏭ next-lecture link: add when it is published)

   {Class} {Subject} | NEET 2027 | Hindi Medium | {Faculty} – Atomic Pathshala
   🌐 https://atomicpathshala.in   📲 App: {link}   💬 Telegram: {link}
   🔔 Subscribe करें – रोज़ live classes.

   #{Chapter} #{Class}{Subject} #NEET2027 #HindiMedium #{Faculty}
   ```
5. **Tags** (10–15): `{chapter}`, `{chapter} class {N}`, `{chapter} neet`, `{sub-topic}`, `{Hindi chapter name}`, `{chapter} hindi medium`, `class {N} {subject}`, `neet 2027 {subject}`, `{faculty}`, `atomic pathshala`.
6. **Playlist:** `{Chapter} ({HI}) | Class {N} {Subject} | NEET 2027 | {Faculty}`
7. **Short?** Yes, if the class has a 30–55 s self-contained explanation or trick. Publish it within 24 h with "Related video" set to this lecture.
8. **Community post?** Yes on test days (poll) or chapter start; otherwise no.

## C. During publication
- [ ] Teaching starts by 0:30. Attendance and homework at the end (rule P1-B).
- [ ] Visibility: {Public live / Scheduled}. Confirm the channel's current practice.
- [ ] Audience: "No, it's not made for kids" (NEET/Class 11–12 content is not "made for kids").
- [ ] Category: Education. Language: Hindi. Captions: auto Hindi.
- [ ] Playlist added at creation.
- [ ] Title, thumbnail, description and tags checked against this sheet.
- [ ] After the stream: recording processed, full length (compare with stream duration), no "Lecture 14 of Class 14"-style typos.
- [ ] End screen: next lecture (or "latest upload") + playlist + subscribe. Cards to the previous lecture where it's referenced.
- [ ] Chapters added from real timestamps. Pinned comment with a practice question and the next-lecture link.
- [ ] Previous lecture's description updated with the ⏭ link to this one.
